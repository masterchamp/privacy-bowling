3. Erhebung und Speicherung personenbezogener Daten
Die App wurde so konzipiert, dass die Datensparsamkeit im Vordergrund steht.
• Lokale Speicherung: Alle von Ihnen eingegebenen Daten (z. B. Spielernamen, Bowling-Ergebnisse, Spielstätten) werden primär lokal in einer Datenbank auf Ihrem Endgerät gespeichert.
• Synchronisationsfunktion (Optional): Die App bietet eine Funktion zur Datensicherung und Synchronisation. Dabei wird die Datenbank (bowling.db) auf einen Server (dresden-wetterstation.de) übertragen oder von dort geladen. Dies geschieht ausschließlich auf Ihre explizite Anweisung hin.
• Keine Identifizierung: Wir erheben keine Daten, um Sie persönlich zu identifizieren (wie Name, Geburtsdatum oder E-Mail), sofern Sie diese nicht selbst als Spielernamen eingeben.
4. App-Berechtigungen
Damit die App ordnungsgemäß funktioniert, benötigt sie Zugriff auf bestimmte Funktionen Ihres Geräts:
• Kamera: Wird verwendet, um Punktestände von Bowling-Monitoren mittels Texterkennung (OCR) zu erfassen. Die Bildverarbeitung erfolgt lokal auf dem Gerät.
• Internet & Netzwerkstatus: Erforderlich für die optionale Synchronisation der Datenbank sowie für die Prüfung auf App-Updates.
• Speicher (Lese-/Schreibzugriff): Erforderlich zum Speichern der lokalen Datenbank und zum Verwalten von Backup-Dateien.
5. Einsatz von Drittanbietern und Diensten
• Google ML Kit: Die App nutzt Google ML Kit zur Texterkennung. Die Analyse der Bilder findet direkt auf Ihrem Endgerät statt ("On-Device"). Laut Google werden dabei keine Bilder an Server übertragen, es können jedoch statistische Daten über die Nutzung der Bibliothek an Google gesendet werden.
• Server-Host: Für die Synchronisation wird Webspace bei einem Hosting-Anbieter genutzt. Die Übertragung erfolgt per FTP/HTTP an die Domain dresden-wetterstation.de.
6. Weitergabe von Daten
Eine Weitergabe Ihrer Daten an Dritte zu Werbezwecken findet nicht statt. Eine Übertragung erfolgt nur im Rahmen der oben genannten Synchronisationsfunktion an den von uns genutzten Serverplatz.
7. Ihre Rechte (DSGVO)
Da die Daten lokal auf Ihrem Gerät gespeichert werden, haben Sie die volle Kontrolle:
• Löschung: Sie können alle Daten jederzeit löschen, indem Sie die App-Daten in den Android-Einstellungen leeren oder die App deinstallieren.
• Auskunft: Sie können die in der App gespeicherten Daten jederzeit in der Benutzeroberfläche einsehen.
• Widerruf: Die Nutzung der Synchronisationsfunktion ist freiwillig und kann jederzeit unterlassen werden.
